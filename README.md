# RHCSA Practice

Vault de estudio para **RHCSA / EX200** (RH104 → RH199 → examen).

Misma idea que [second-brain](https://github.com/arceprogramando/second-brain): Markdown + Obsidian + Git. Acá el foco es práctica de labs, objetivos del examen y el informe de progreso.

Abrí esta carpeta como **vault** en Obsidian. El mapa está en `tableros/inicio.md`.

## Qué hay adentro

```text
diario/              días de estudio, por año
temas/               hilos EX200 que se repiten
tableros/            mapa, progreso, mejoras
plantillas/          diario y lab
inbox.md             recortes sueltos hasta acomodarlos
adjuntos/            capturas y PDFs sueltos (si hace falta)
rhcsa-lab-base/      pack de labs, cheatsheets e informes
```

## Pack de labs

El material concreto vive en `rhcsa-lab-base/`:

- cheatsheets (comandos, objetivos EX200, índice RH199)
- labs (simulacros, compreview, permisos, links, nbaud)
- rhcsa-lab (server1 + server2)
- informes (PDF de progreso + scripts)
- scripts-practica, pdfs-curso, canvas

Detalle: `rhcsa-lab-base/README.txt`.

## Diario de estudio

Cada día de práctica tiene su propio archivo:

```text

```

Usá Daily notes en Obsidian (plantilla `plantillas/diario`). Enlazá temas con wikilinks: `[[SELinux]]`, `[[systemd]]`.
